# TwinBee Clone - ツインビー クローンゲーム

ファミコンの名作シューティングゲーム「ツインビー」のクローンゲームです。HTML5 Canvas と JavaScript で作成されており、PC・Mac・スマートフォンでプレイできます。

## 🎮 ゲームの特徴

- **縦スクロールシューティング**: 上から迫る敵を撃墜しながら進んでいきます
- **空中攻撃と地上攻撃**: ショットで空中の敵を、爆弾で地上の敵を攻撃
- **ベルシステム**: 雲を撃つとベルが出現。さらに撃つと色が変化してパワーアップ！
  - 🟡 黄色: ボーナス得点
  - ⚪ 白色: ツイン砲（2連装ショット）
  - 🔵 青色: スピードアップ
  - 🔴 赤色: バリア
- **アイテムシステム**: 地上敵を破壊するとフルーツやスターが出現
- **レスポンシブデザイン**: PC・Mac・スマホ対応
- **タッチ操作**: スマホでも快適にプレイできる仮想コントローラー

## 🎯 操作方法

### PC / Mac
- **移動**: 矢印キー (←↑↓→)
- **ショット**: Z キー
- **爆弾**: X キー

### スマートフォン
- **移動**: 画面左の十字キー
- **ショット**: SHOT ボタン
- **爆弾**: BOMB ボタン

## 🚀 プレイ方法

### GitHub Pages でプレイ

1. このリポジトリの Settings → Pages に移動
2. Source を "Deploy from a branch" に設定
3. Branch を選択（例: `claude/twin-bee-game-clone-01CB2bPzh9pYfKmsTdv4JDUv` または `main`）
4. Save をクリック
5. 数分後、表示される URL にアクセス（例: `https://yuk1-kondo.github.io/now-here/`）

### ローカルでプレイ

ローカル環境で実行する場合は、簡単な Web サーバーが必要です：

```bash
# Python 3 を使用する場合
python -m http.server 8000

# Node.js の http-server を使用する場合
npx http-server
```

その後、ブラウザで `http://localhost:8000` にアクセスしてください。

## 🎮 ゲームのコツ

1. **ベルを撃ち続ける**: 雲から出たベルを連続で撃つことで、より強力なパワーアップが手に入ります
2. **地上敵を優先的に破壊**: アイテムをゲットしてスコアアップ！
3. **スターの使いどころ**: 敵が多い時にスターを取ると一気に全滅させられます
4. **バリアの活用**: 赤ベルのバリアは複数回ダメージを防げます
5. **スピードアップの調整**: 青ベルでスピードアップしますが、速すぎると操作が難しくなります
